    Class Ship

    A Ship is the player's character in the game of Asteroids. The Ship has forwards and backwards propulsion as well as steering. This class provides a method, Ship.loadInputs, which can take 3 number inputs for controlling the Ship. This allows for the NEAT algorithm to take control of a Ship using the outputs directly from the AI.
